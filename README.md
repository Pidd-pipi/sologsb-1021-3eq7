# 濒危语言词典编辑与审校工具

`sologsb-1021` 是一个本地优先的濒危语言词典工作台，使用 Nuxt 3、Vue 3、Pinia 和 TDesign Vue Next 从零构建。

## 功能

- 维护词形、发音说明、方言变体、词性、例句、来源、同义词和编者备注。
- 主审/编辑角色分离：编辑维护词条与回复；确认、退回、解决意见和字段冲突裁定仅主审可操作。
- 词条支持草稿、待审、争议、已确认四种状态；已确认词条被编辑或由过期离线包带入改动后，会退回待审并要求重新确认。
- 审校意见可绑定到具体字段，编辑可以逐条回复；主审负责打开、退回和解决。
- 导入离线审校包时按“本地 / 基础版本 / 离线包”三方合并：无冲突改动直接纳入；同字段两边都改时保留两份并等待主审定夺。
- 整批合入、失败可原样重试；通过稳定 `packageId` 去重，同一个包重复导入不会增加记录。
- 自动检测词形、同义词和释义高度相似的重复词条。
- 重复词条并排比较，可选择主条并逐字段选择“主条 / 另一条 / 拼接”；变体、例句、来源和意见全部保留。
- 删除词条前扫描其他词条的同义词、释义和例句引用，列出全部影响并阻止无意删除。
- 旧版本地数据升级时自动补齐批次、操作人和角色信息；新版审校包携带基础快照、批次、角色和历史，可继续交给下一位。
- 每次提交前保存完整版本快照，支持撤销重做、版本恢复和操作审计。
- 全文搜索、状态筛选、方言筛选，以及 J/K、搜索、查重、版本和通用撤销快捷键。
- 使用浏览器 localStorage 离线保存，刷新或断网后继续编辑。

## 技术栈

- Nuxt 3.21
- Vue 3.5
- Pinia 4
- TDesign Vue Next 1.20
- TypeScript 5.9

## 开发

```bash
npm install
npm run dev
```

开发服务器使用 Nuxt 默认端口，不在源码中硬编码宿主端口。

## 生产构建

```bash
npm run build
```

项目使用 Nuxt 静态生成，产物位于 `.output/public/`。可在本地运行：

```bash
npm run preview
```

## Docker

```bash
docker build -t sologsb-1021 .
docker run --rm -p 10021:80 sologsb-1021
```

构建阶段生成静态站点，运行阶段由 nginx 监听容器 `80`。宿主端口 `10021` 仅由根端口表或部署命令映射。

## 数据说明

词典数据、版本历史、导入批次与审校角色保存在当前浏览器。「备份」导出工作区 JSON；「导出审校包」生成可交接的 `offline-review-package/v2`，其中包含词条、版本、审计、角色、当前批次及用于三方合并的基础快照。仍有字段冲突或过期待重审词条时不能导出交付审校包。
